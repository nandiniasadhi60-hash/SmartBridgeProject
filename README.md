# Human Development Index Prediction

## 📌 Project Overview
The Human Development Index (HDI) Prediction project uses Machine Learning to predict the Human Development Index based on various socio-economic indicators. This project helps analyze development trends by providing accurate HDI predictions using historical data.

## 🚀 Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Machine Learning model training
- Model evaluation and comparison
- HDI prediction using user input
- Simple and user-friendly web interface

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Flask
- HTML
- CSS

## 📊 Workflow
1. Collect the dataset.
2. Preprocess and clean the data.
3. Perform Exploratory Data Analysis.
4. Train multiple Machine Learning models.
5. Evaluate model performance.
6. Save the best model.
7. Build a Flask web application.
8. Predict the Human Development Index from user inputs.

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Human-Development-Index-Prediction.git
```

Move into the project folder:

```bash
cd Human-Development-Index-Prediction
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser and visit:

https://human-development-index-predictioin.onrender.com
